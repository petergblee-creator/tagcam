사진 분석 (선택)

Anthropic API 키를 넣으면 사진 내용을 분석해 선택지를 추천합니다. 키는 이 폰에만 저장되고, 사진은 분석할 때만 Anthropic으로 전송됩니다. 비워 두면 분석 없이 씁니다.

백업

폴더·태그·선택지 목록을 파일로 내보내거나 불러옵니다. 폰을 바꿀 때 씁니다.

찍은 뒤 자르기 → 이름(날짜_시간_선택지) → 폴더·태그 순서로 진행합니다. 태그는 사진 파일 안에 기록되어 PC에서도 보입니다.
